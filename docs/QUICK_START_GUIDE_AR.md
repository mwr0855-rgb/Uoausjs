## 🚀 التشغيل في 5 خطوات

### 1️⃣ فك الضغط
```bash
unzip Khatwa_Internal_Audit_System.zip
cd webapp
```

### 2️⃣ تثبيت المكتبات
```bash
npm install
```

### 3️⃣ إعداد البيئة
```bash
cp .env.example .env.local
```

### 4️⃣ تشغيل النظام
```bash
npm run dev
```

### 5️⃣ فتح المتصفح
```
http://localhost:3000/internal-audit
```

## ✨ الميزات السريعة

### لوحة المعلومات
عرض شامل لحالة المراجعة مع رسوم بيانية تفاعلية

تصنيف وإدارة المخاطر بمصفوفة تفاعلية

### التحليل المالي
تحليل تلقائي للقوائم المالية مع كشف العلامات التحذيرية

برنامج مراجعة سنوي يغطي 9 دورات مالية

### التقارير
تقارير احترافية قابلة للتصدير

متابعة الامتثال للمعايير الدولية (IIA, COSO, ISO)
