## 🚀 التثبيت والإعداد

### الخطوة 1: فك الضغط

```bash
# لنظام Windows
انقر مزدوج على ملف .zip

# لأنظمة Linux/macOS
unzip Khatwa_Internal_Audit_System.zip
# أو
tar -xzf Khatwa_Internal_Audit_System.tar.gz
```

### الخطوة 2: الدخول إلى مجلد المشروع

```bash
cd webapp
```

### الخطوة 3: تثبيت المكتبات

```bash
npm install
```

أو باستخدام yarn:

```bash
yarn install
```

أو باستخدام pnpm:

```bash
pnpm install
```

### الخطوة 4: إعداد ملف البيئة

```bash
# نسخ ملف البيئة النموذجي
cp .env.example .env.local
```

قم بتعديل ملف `.env.local` وأضف الإعدادات التالية:

```env
# عنوان API الرئيسي
NEXT_PUBLIC_API_URL=http://localhost:5000

# إعدادات قاعدة البيانات (اختياري)
DATABASE_URL=postgresql://user:password@localhost:5432/khatwa_db

# مفتاح JWT (اختياري)
JWT_SECRET=your-secret-key-here

# بيئة العمل
NODE_ENV=development
```

### الخطوة 5: تشغيل المشروع

```bash
# للتطوير
npm run dev

# سيتم فتح المشروع على:
# http://localhost:3000
```

```bash
# للإنتاج
npm run build
npm run start
```

### 3. التحليل المالي الذكي (Financial Analysis)

#### الوصول
```
/internal-audit/financial-analysis
```

#### الميزات
- تحليل تلقائي للقوائم المالية
- حساب النسب المالية
- التحليل الأفقي والرأسي
- كشف العلامات التحذيرية (Red Flags)
- تقارير تفصيلية

#### كيفية الاستخدام

1. **رفع القوائم المالية**
   ```
   - انقر على "رفع قوائم مالية"
   - اختر الملف (Excel, CSV, JSON)
   - أو أدخل البيانات يدوياً
   ```

2. **تحليل القوائم**
   ```
   النظام سيقوم بـ:
   - حساب النسب المالية تلقائياً
   - تحليل السيولة
   - تحليل الربحية
   - تحليل النشاط
   - تحليل الرفع المالي
   ```

3. **النسب المالية المحسوبة**

   **نسب السيولة:**
   - النسبة الجارية = الأصول المتداولة ÷ الخصوم المتداولة
   - النسبة السريعة = (الأصول المتداولة - المخزون) ÷ الخصوم المتداولة
   - النسبة النقدية = النقدية ÷ الخصوم المتداولة

   **نسب الربحية:**
   - هامش الربح الإجمالي = (الربح الإجمالي ÷ المبيعات) × 100
   - هامش الربح التشغيلي = (الربح التشغيلي ÷ المبيعات) × 100
   - هامش الربح الصافي = (صافي الربح ÷ المبيعات) × 100
   - العائد على الأصول ROA = (صافي الربح ÷ إجمالي الأصول) × 100
   - العائد على حقوق الملكية ROE = (صافي الربح ÷ حقوق الملكية) × 100

   **نسب النشاط:**
   - معدل دوران المخزون = تكلفة البضاعة المباعة ÷ متوسط المخزون
   - معدل دوران الذمم = المبيعات الآجلة ÷ متوسط الذمم المدينة
   - معدل دوران الأصول = المبيعات ÷ إجمالي الأصول

4. **العلامات التحذيرية**
   
   النظام يكتشف تلقائياً:
   - ⚠️ انخفاض السيولة
   - ⚠️ تدهور الربحية
   - ⚠️ ارتفاع المديونية
   - ⚠️ ضعف النشاط
   - ⚠️ مشاكل في التدفقات النقدية

## ❓ الأسئلة الشائعة

### التثبيت والإعداد

**س: ما هي متطلبات التشغيل؟**
ج: Node.js 18+, npm 9+, 4GB RAM كحد أدنى، ومتصفح حديث.

**س: هل يعمل النظام بدون إنترنت؟**
ج: نعم، النظام يعمل محلياً بدون إنترنت. الإنترنت مطلوب فقط للتحديثات.

**س: كيف أغير المنفذ (Port) الافتراضي؟**
ج: عدّل ملف `package.json` في قسم scripts:
```json
"dev": "next dev -p 8080"
```

### الاستخدام

**س: كيف أضيف مستخدمين جدد؟**
ج: حالياً النظام لا يحتوي على نظام مصادقة. يمكن إضافته لاحقاً حسب الحاجة.

**س: هل يمكن تخصيص التقارير؟**
ج: نعم، جميع التقارير قابلة للتخصيص عبر صفحة الإعدادات.

**س: كيف أحفظ البيانات؟**
ج: حالياً البيانات مخزنة محلياً. يمكن ربط النظام بقاعدة بيانات لاحقاً.

### المشاكل الشائعة

**س: النظام لا يعمل بعد التثبيت**
ج: تأكد من:
1. تثبيت Node.js بالنسخة الصحيحة
2. تشغيل `npm install` بنجاح
3. عدم وجود أخطاء في terminal

**س: الواجهة لا تظهر بالعربية**
ج: تأكد من إعدادات المتصفح، واضبط اللغة من إعدادات النظام.

**س: التقارير لا تُصدَّر**
ج: تأكد من أذونات الكتابة في مجلد التنزيلات.
